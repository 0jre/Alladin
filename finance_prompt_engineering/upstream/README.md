## 🚀 How to Use
1. **Find your Category:** Navigate through the table of contents to find the task you're working on.
2. **Expand the Card:** Click any dropdown to reveal the structured prompt template.
3. **Copy the Prompt block:** Copy the text located in the `text` block.
4. **Fill Placeholders:** Replace bracketed areas like `[COMPANY]` with your actual data.
5. **Execute in Claude:** Paste into Claude to generate institutional-grade output.

## ⚠️ Disclaimer
All prompts are universal analytical frameworks. Actual outputs will vary depending on the data you provide. Every AI output requires review by a qualified analyst before use in any professional setting.
